# 📦 SMALLBOXCLOUD — Control de Caja Chica en la Nube
**Cliente:** Congelados Herbania, S.A.  
**Código del Proyecto:** `SEP26_04 SMALLBOXCLOUD`  
**Ubicación:** `00. Antigravity_CAIC\SEP26_04 SMALLBOXCLOUD`  
**Evolución:** Basado en el motor de lectura forense de facturas INDIRA.

---

## 🎯 Objetivo
Digitalización y control desatendido de facturas escaneadas desde la impresora multifunción de Herbania:
1. Recepción desatendida vía Power Automate / Webhook.
2. Extracción forense con OCR (Tesseract / PyMuPDF) y Vision AI.
3. Despliegue en contenedor Docker para alojamiento cloud 24/7 sin dependencia de hardware local.
